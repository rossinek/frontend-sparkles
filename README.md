# Frontend Sparkles

A collection of frontend experiments exploring motion, playful interfaces, and visual interactions. Each experiment is a small, self-contained demo built around a specific idea.

[Explore the experiments](https://rossinek.github.io/frontend-sparkles/)

## Experiments

- [Particle Flip](./particle-flip/README.md) — a 3D page transition where a card breaks into particles, twists with spring motion, and reforms as the next page. A small portfolio serves as the demo content. [Open demo](https://rossinek.github.io/frontend-sparkles/particle-flip/).
