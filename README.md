# Frontend Sparkles

A playground for frontend experiments, visual ideas, and small interactive projects.

## Project Structure

Each experiment lives in its own directory and is either a static HTML file or a small pnpm project.

## Conventions

- All documentation, text, and page content is written in English.
- pnpm is the package manager for every project that needs packages.
- Vue is used for projects that require interactivity.
- Each approved change is committed as work progresses.

See [AGENTS.md](./AGENTS.md) for the repository guidelines.

## Getting Started

Open a static project's HTML file in a browser, or follow the setup instructions in a pnpm project's directory.

## Experiments

- [Particle Flip](./particle-flip/README.md): a Three.js page-transition experiment where a card breaks into particles, twists in 3D, and reforms as the next page. A Vue portfolio provides the demo content.
